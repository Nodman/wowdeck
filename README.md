# WoWDeck test build 1.3.1-test.1

`WoWDeck.zip` is a device-test build of the branch `fix/large-addon-zip-memory`
(commit 05d8bfd): the fix for "Engine process exited" when installing or
updating addons with many large files. It is not an official WoWDeck release.

Install: Decky → Settings → Developer → Install Plugin from URL

    https://github.com/Nodman/wowdeck/raw/test-build/WoWDeck.zip

This build has no bundled CurseForge key: set your own under Options → CurseForge.

This branch only carries the build and can be deleted after testing.
